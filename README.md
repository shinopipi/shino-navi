# shino-navi（しのナビ）

スマホのブラウザで動く、車用のナビアプリです。

## できること

- 住所・施設名で目的地を検索（地図の長押しでも指定できます）
- ルートの距離・所要時間・到着予定を表示
- 曲がる場所を矢印と日本語の音声で案内（約500m手前と直前）
- ルートを外れたら自動で再検索
- 速度メーター、案内中は画面が消えない
- テスト走行（ルート上を3倍速で走るシミュレーション）
- 交通規制の表示：一方通行（青い矢印）、駐車禁止、時間帯通行禁止（今が禁止時間なら赤、時間外はオレンジ）
- 信号マーク、「次の信号まで○m」、「2つ目の信号を右折です」の案内
- 曲がる場所の300m手前から「3D拡大図」：実際の地図データ（道路の形・ビルの高さ）から交差点を立体表示し、交差点名・車線・高速の方面看板を重ねる（地図データが読めない時は手描きの絵）。一般道は交差点（横断歩道・車線の矢印・信号・オレンジの進路矢印）、高速道は分岐（防音壁・緑の方面看板・進路矢印）
- 高速道路に入ると自動で高速道路モード（緑の案内板、この先の IC・JCT・SA・PA・料金所の一覧と到着予想時刻）
- リアルタイム渋滞（TomTom）でルート候補を最大5件。重い渋滞のない最速ルートを「おすすめ」に。渋滞区間を色分け表示、案内中も3分ごとにより早いルートを確認（設定でTomTomのAPIキーが必要）
- ルート検索は検索した時刻の時間帯通行禁止を考慮（Valhalla。つながらない時は OSRM）

## 使い方

GitHub Pages で公開したページを iPhone の Safari で開き、「ホーム画面に追加」するとアプリのように使えます。
現在地を使うため、https のページで開いてください。

## 使っているもの

- 地図：OpenFreeMap（OpenStreetMap）＋ MapLibre GL。読み込めない時は国土地理院の地図
- ルート：Valhalla 公開サーバー（FOSSGIS）、予備に OSRM 公開デモサーバー
- 規制データ：OpenStreetMap（Overpass API）。登録されていない規制は表示されません
- 検索：Nominatim（OpenStreetMap）、国土地理院 住所検索
- 表示：進行方向が上の3D地図、車線案内、夜モード、横画面対応

渋滞情報はありません。運転中は画面を操作しないでください。
