# shino-navi（しのナビ）

スマホのブラウザで動く、車用のナビアプリです。

## できること

- 住所・施設名で目的地を検索（地図の長押しでも指定できます）
- ルートの距離・所要時間・到着予定を表示
- 曲がる場所を矢印と日本語の音声で案内（約500m手前と直前）
- ルートを外れたら自動で再検索
- 速度メーター、案内中は画面が消えない
- テスト走行（ルート上を3倍速で走るシミュレーション）

## 使い方

GitHub Pages で公開したページを iPhone の Safari で開き、「ホーム画面に追加」するとアプリのように使えます。
現在地を使うため、https のページで開いてください。

## 使っているもの

- 地図：OpenFreeMap（OpenStreetMap）＋ MapLibre GL。読み込めない時は国土地理院の地図
- ルート：OSRM 公開デモサーバー（OpenStreetMap）
- 検索：Nominatim（OpenStreetMap）、国土地理院 住所検索
- 表示：進行方向が上の3D地図、車線案内、夜モード、横画面対応

渋滞情報はありません。運転中は画面を操作しないでください。
